# Chem-S2-Review

A Streamlit-based Honors Chemistry Semester 2 review module focusing on balancing chemical equations.

## Setup

1. Create and activate your Python environment.
2. Install dependencies:
   ```bash
   python3 -m pip install -r requirements.txt
   ```

## Run

```bash
streamlit run module1.py
```

## Notes

- `requirements.txt` includes `streamlit` and `fpdf`.
- `module1.py` generates a downloadable PDF report using `fpdf`.
